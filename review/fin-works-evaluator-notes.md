# 肥育向け新5作業 評価者メモ

- 豚房・豚舎に入るときは、農場の防疫ルールに従う（見回り・健康チェック、飲水器の点検ほか全作業共通）。
- 見回り・健康チェック: 第一報の「どの豚か（マーキング色など）」は report-template が採点。印付けと翌日の追跡は mark-followup が採点。
- 飲水器の点検: flow-measure（全ニップルの流量測定）と給餌 water-first（給餌前のニップル押下確認）は同じ受験者に併用しない。ウォーターカップ式の豚房は flow-measure を対象外にする。
- 飲水器の点検: freeze-outage は季節外なら実地で見られない。口頭で「最初の行動」を聞いて採点する。
- 換気設定確認（ウインドレス）: 当日に見られるのは read-record と verify-actual。change-rule・weekly-review・power-backup は口頭試問と記録用紙の確認で採点する。カーテン式の農場には割り当てない。
- 最高最低温度計は換気・温度管理（肥育）の read-temp が採点する。換気設定確認では採点しない。
- 口頭で確かめる種目（当日に見られないことが多い）: 見回り=urgency-judge・mark-followup の翌日確認、飲水器=freeze-outage・clog-leak（不具合が無い日）、換気・温度=read-temp の3回読み・fan-failure-first・季節外の pig-signs/never-stop、換気設定=change-rule・weekly-review・power-backup、密度=split-judge・pen-count-fit・area-calc。
- change-rule: 「決められた人」本人が受験する場合は、変更前の相談先を言えれば L4 とする。
- change-rule・weekly-review・power-backup は口頭試問＋記録用紙で採点する。verify-actual の手持ち温度計は用意物（無い農場は verify-actual の L4 を評価しない）。
- 換気設定確認の change-rule: L2=指示があれば触らないが、変更が必要と思っても上長に相談せず放置する（L1=自分で触る）。L4=指示がなくても触らず、変更は決められた人に委ねる（相談の有無は L3 で見る）。不触は change-rule だけで採点し、read-record では採点しない。
- 換気設定確認の read-record: L3=読み取りと転記、L4=全項目を漏れなく読み前週の記録と画面値の食い違いに気づく。
- 換気設定確認の weekly-review: L3 は今週の設定記録と頭数・体重帯を用紙にそろえて渡せるか（口頭確認）、L4 は頭数・体重帯をそろえた設定記録を毎週上長に渡し、農場が決めた見直し時期に当たると自分から伝えるか（当日の記録用紙で判定）。最高最低温度計は採点しない。
- power-backup のブレーカー確認と vent-temp の fan-failure-first は同一人物に割り当てない。
- 密度: area-calc は計算だけ、pen-count-fit は移動後の現物照合だけ（上限頭数は area-calc で出した値か農場の表を使う）。全頭が同時に横になれるかは crowd-signs が採点する。
- 飲水器の点検: season-record は「今の季節の点検ポイントを答える」1行動。春秋は直近の季節の点検を口頭で聞く。L4 は実際の点検と異常の上長報告、L5 は季節で見る点が変わる理由の指導で採点する（記録のしかた・予備ニップルの確認は資料に無いため採点しない）。
- 換気・温度（肥育）: ファンの不調や有害ガスの対応で扉やカーテンを開けるときは、農場の防疫ルールに従い、必要な間だけ開けて代替換気の手順と両立させる（扉開放時の防疫注意。代替換気で開ける間は閉めさせない）。
- power-backup: 発電機の起動訓練を受けていない受験者は、決められた人を呼ぶ行動で L4。代替換気の手順が無い農場は、当日農場の手順書で確かめる。
- 375px 幅: 種目の段階文が長い vi/id は折り返しが増える。画面の文字は最小限の方針のため、必要なら vi/id の括弧内の例示から削る。
- 見回り・健康チェック: 異常豚がいない日は urgency-judge・report-template を想定事例の口頭質問（例「跛行の豚を見つけたら、誰にどう伝えますか」）で採点する。治療 No.04・死獣 No.37 infect-signs・move-order と同じ受験者の8枠には入れない。
- 換気・温度（肥育）: pig-signs L4 と fan-failure-first L4 の「豚の呼吸を見る」は同一の観察。一方で採点したら、もう一方では同じ観察を二重に数えない。
- 密度: pen-count-fit と count-record の「豚房の豚を数える」は1回の実数え行動で両方に使う（二重に数えさせない）。
- 密度: 口頭確認種目の L4 聞き方の例（split-judge）「この豚房が混んでいるのに気づきました。何を確かめて、誰に何を伝えますか」。
