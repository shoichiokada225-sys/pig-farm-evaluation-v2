## シートの形
### 受験者（名簿）— 見出しは1行目。記入の約束は「被評価者」の見出しのメモにもある
| 列 | 見出し | 書き方 |
|---|---|---|
| A | 農場 | プルダウン（農場一覧タブ）から選ぶ。農場が決まっていない人は **所属未確定** |
| B | 被評価者 | 1人1行。同じ農場に同じ名前の人がいる時は `Nam(A)` `Nam(B)` のように区別する |
| C〜J | 作業1〜作業8 | プルダウンの**作業名**から選ぶ（**No. は入らない**＝入力規則で拒否される）。空欄の人は（農場共通）行の作業 |
| K | 旧名 | 名前を直した時だけ、直す前の名前（複数は「、」区切り）。直す前の名前で保存した記録も「済」に数える |

旧名の列は見出しが「旧名」（または「別名」）なら位置は問わない。前の版の `setup` で作ったシートには無いので、使う時に見出し「旧名」の列を足す。

- **（農場共通）行**: 被評価者の欄に `（農場共通）` と書き、農場と作業を入れる。その農場で作業が空欄の人全員に使われる。1農場1行（2行あるとアプリが警告し、作業を合わせて使う）
- **所属未確定**: 後で農場を決めてよい。決めたら A列を書き換えて、アプリで「名簿を更新」。済んだ人は済んだまま（名簿で同じ名前が1人だけなら、名前で数える）
- **名前を直す時**（Nguyen Van A → Nguyễn Văn A など）: B列を直し、K列（旧名）に元の名前を書く
- **備考の列は自由に足してよい**（「作業メモ」など）。ただし見出しを「作業」+数字にしない（作業列として読まれ、プルダウンがかかる）
- 作業を 9つ以上にしたい時は、見出し `作業9` の列を足して `setup` を再実行
- 読むのは見出しで決めた列だけ。列の順番を入れ替えても読める

### 農場一覧
- A列=農場名（1行目は見出し）。最初の `setup` で、名簿の初期データ（無ければ受験者タブ）の農場＋所属未確定から作る
- 農場を増やす・名前を直す時はここを直す（受験者タブのプルダウンに反映）。`setup` を再実行しても上書きしない
- アプリは農場名の全角半角・空白のゆれを1つにまとめ、「大田原」と「大田原農場」のような似た名前の小さい農場は「農場名のゆれ」と警告する

### 作業一覧
- `setup` のたびに作り直す（アプリの作業カタログと同じ 40作業）。手で直さない

### 評価者名のタブ
- 評価者ごとに自動で作られる。1種目=1行。記録IDで上書きされるので、再送・編集しても重複しない
- 列は A〜O の15列: 記録ID・評価日・評価者・被評価者・農場・カテゴリ・作業・種目・スコア・コメント・作業平均・セッション平均・全体所感・送信日時・**やり直し元**
- **O列「やり直し元」**（GAS `2026-09-24f` 以降）: アプリで「やり直し」として採点した記録にだけ、置き換えた前回の記録ID（複数は半角空白区切り）が入る。前の版で作ったタブは、次に書き込んだ時に O1 に見出しが付く（前からある行の O列は空）
- **アプリで記録を削除すると、シートの行も消える**（どの評価者タブにあっても。圏外の時は電波が戻ってから）
- E列「農場」は**保存した時の農場**（所属未確定のまま採点した人は所属未確定）。後から直さない
- 評価者タブ自体に列を足さない（GAS が行を消して書き直すので、足した列の値がずれる）

## 農場別に集計する（「集計（自動）」タブ）
`setup` が「集計（自動）」タブを作り、**全部の評価者タブを1本の式で**並べる。手で式を書かない・直さない。

| 行・列 | 中身 |
|---|---|
| 1行目 | 説明（A1 は「記録ID」ではない＝評価者タブと取り違えない） |
| 2行目 | 見出し（評価者タブの15列＋P「今の農場」＋Q「採否」） |
| A3 | `=LET(d,{'評価者A'!A2:O;'評価者B'!A2:O;…},IFERROR(FILTER(d,CHOOSECOLS(d,1)<>""),""))`＝**空行を除いて**縦に並べる（2人目以降の評価者の行が数百行の空行の後ろに飛ばない） |
| P3 | 今の農場＝`MAP` で全行に1本の式（下へコピーしない）。受験者タブの被評価者 → 農場。見つからなければ旧名の列を「、」区切りの**完全一致**で引く（`Nam` が `Hoang Nam` に当たらない） → それも無ければ記録時の農場（E列） |
| Q3 | 採否＝どこかの行の O列「やり直し元」にこの記録IDがあれば **やり直し前**、それ以外は **採用** |

- **数えるのは Q列が「採用」の行だけ**（やり直しは最新の試行を採用。前回の点を平均や件数に混ぜない）。ピボットテーブルは範囲 `'集計（自動）'!A2:Q`、フィルタ「採否＝採用」、行＝「今の農場」
- **評価者タブが増えた時**: GAS が評価者タブを新しく作った時（当日、初めての評価者名で送信した時・「〜_記録」タブ）に、式を自動で作り直して足す。評価者タブを手で消した・集計（自動）タブを消した時は、`setup` を再実行すると作り直す
- 式の中の受験者タブの列（被評価者・農場・旧名）は、`setup`／作り直しの時の見出しの位置で決まる。受験者タブの列を並べ替えたら `setup` を再実行する
- 評価者タブの「農場」（E列）は保存した時の値。所属が決まった人・農場名を直した人は P列の今の農場で数える
- 同じ名前が2農場にいる人は `Nam(A)` のように区別しておく（XLOOKUP は最初の1人を返すため）
- 作り直すのは GAS 自身が作った集計タブだけ（タブの番号を文書プロパティ `HSS_SUMMARY_TAB_ID` に控えている）。同じ名前「集計（自動）」のタブを手で作っても上書きしない（その時は GAS の集計タブは作られない）。自分用の表は別の名前のタブに作り、`'集計（自動）'!A2:Q` を参照する

GAS が行を消し・書き直すのは、**GAS 自身が作った評価者タブだけ**（タブの番号を文書プロパティ `HSS_EVAL_TAB_IDS` に控えている）。
集計タブ・タブの複製・値を貼った控えは、見出しが同じでも触らない。評価者タブを手で作ったり、控えを評価者名に改名したりしない。
